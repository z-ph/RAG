## 1. 产品概述

Knowledge Copilot 是一款基于 **RAG（检索增强生成）** 架构的智能知识库问答系统。用户通过自然语言提问，系统从已入库文档中检索相关片段，基于检索结果生成精准回答，并标注引用来源。

| 能力 | 说明 |
|------|------|
| 智能问答 | 基于知识库的流式对话，带思考过程和引用来源 |
| 图片问答 | 上传图片并提问，支持多模态视觉理解 |
| 文档管理 | 上传、查看、下载、删除、重建索引知识库文档 |
| 权限管控 | 匿名访客、普通成员、管理员三级角色 + RBAC 细粒度权限 |
| 用户管理 | 用户/角色/权限的完整生命周期管理 |
| 注册码机制 | 管理员发放一次性注册码，控制用户注册 |
| 提示词管理 | 动态调整系统提示词模板，控制 AI 行为 |

## 2. 角色体系

系统采用三级角色模型，不同角色可访问的功能逐级递增。

### 2.1 匿名访客（未登录）

- 无需账号即可使用核心问答功能
- 可浏览公开文档列表、查看文档详情、下载文档
- 不可上传或删除文档，不可访问管理后台

### 2.2 普通成员（USER）

- 拥有匿名访客的全部能力
- 登录后可见完整的文档列表
- 可修改自己的登录密码
- 不可上传或删除文档（需管理员权限）
- 不可访问管理后台

### 2.3 管理员（ADMIN / 超级管理员）

- 拥有普通成员的全部能力
- 可上传和删除知识库文档
- 可访问管理后台，进行用户、角色、权限、注册码、提示词管理

## 3. 功能模块

### 3.1 智能问答（主界面 `/rag/`）

主界面为对话式布局：顶部工具栏、中间消息流、底部输入区。

#### 提问方式

- **文本提问**：在底部输入框输入问题，按 `Enter` 发送（`Shift + Enter` 换行）
- **图片提问**：点击输入框左侧图片图标，选择图片后输入问题并发送（支持 jpg/jpeg/png）

#### 回答展示

- **流式输出**：AI 回答以打字机效果逐字呈现
- **思考过程**：可折叠的思考卡片，展示模型推理链及耗时
- **来源片段**：回答下方可展开，列出引用的文档段落、文件名及相似度得分
- **复制回答**：每条 AI 消息右上角可一键复制完整回答

#### 对话控制

- **取消生成**：生成中发送按钮变为「停止」按钮，点击可中断当前流
- **清空对话**：顶部工具栏可清空当前会话上下文
- **对话持久化**：对话历史自动保存在浏览器本地，刷新页面后恢复

#### 检索参数

顶部工具栏提供 `maxResults` 和 `minScore` 两个检索参数：

- `maxResults`：检索片段数量上限，前端默认值为 `4`
- `minScore`：最低语义分数阈值，前端默认值为 `0.5`
- 低于 `minScore` 的片段不会进入回答上下文

---

### 3.2 文档控制台（`/rag/documents`）

点击主界面顶部「文档控制台」按钮，进入独立的文档管理页面。

#### 文档列表页

- 展示已入库文档的文件名、文档 ID 和切分段数
- 匿名访客仅见公开文档；登录后可见完整列表

#### 文档上传（管理员专属）

- **上传文档**：支持多选文件批量上传
- **上传文件夹**：递归上传整个文件夹中的合法文件
- **支持格式**：`.pdf`、`.txt`、`.doc`、`.docx`
- **实时进度**：通过 SSE 实时展示解析、切分、向量化、入库各阶段进度
- **取消上传**：上传过程中可随时中断

#### 文档操作

- **查看**：进入独立的文档详情页，展示标题、分类、关键词标签、全部文本段落
- **下载**：弹出下载链接弹窗，可复制链接或直接下载原文件
- **删除**（管理员专属）：移除文档及其所有向量片段

#### 文档详情页（`/rag/documents/{documentId}`）

- 展示文档标题、原文件名、分类、关键词、时间和切分段落
- 顶部提供返回按钮，可回到文档控制台列表页
- 在详情页内同样可以直接下载原文件

---

### 3.3 用户认证（右侧抽屉）

点击顶部用户区域，从右侧滑出认证抽屉。

#### 登录 / 注册

- **登录**：输入用户名和密码即可登录，前端会保存 `access token` 与 `refresh token`
- **注册**：需持有管理员发放的一次性注册码，填写用户名、密码和注册码完成注册
- **静默续期**：当 `access token` 过期时，前端会自动使用 `refresh token` 换取新 token，并自动重试当前请求

#### 已登录状态

- 显示用户名和角色标签（管理员 / 成员）
- 提供「退出」按钮注销当前会话

---

### 3.4 管理后台（`/rag/admin` 路径，管理员专属）

管理员点击顶部「管理」按钮进入管理后台。后台采用左侧可折叠导航 + 右侧内容区的独立页面布局。

导航菜单：概览、用户管理、角色管理、权限管理、注册码管理、提示词管理。右上角提供「返回对话」链接、修改密码和退出登录。

#### 3.4.1 概览仪表板

展示系统统计卡片：用户总数、角色总数、权限总数、注册码总数。点击卡片可跳转到对应管理页面。

#### 3.4.2 用户管理

用户列表展示用户名、角色、启用状态、创建时间。

- **创建用户**：填写用户名、密码并分配角色
- **编辑用户**：调整角色和启用/禁用状态
- **重置密码**：管理员可重置任意用户的密码
- **删除用户**：移除用户账号

#### 3.4.3 角色管理

角色列表展示角色代码、名称、描述和已分配权限标签。

- **创建角色**：设置代码、名称、描述并选择权限
- **编辑角色**：修改名称、描述和权限分配
- **删除角色**：仅非内置角色可删除（SUPER_ADMIN、ADMIN、USER 为内置角色，不可删除）

#### 3.4.4 权限管理

展示系统所有已定义的权限，按模块分组。权限由系统预设，不可自行创建或修改，仅通过角色管理进行分配。

#### 3.4.5 注册码管理

管理一次性注册码，展示注册码、备注、创建者、有效期和状态（可用 / 已使用 / 已禁用 / 已过期）。

- **创建注册码**：填写备注和有效期（可选，不填则永不过期）
- **禁用注册码**：对可用状态的注册码手动禁用
- **删除注册码**：永久删除注册码记录

#### 3.4.6 提示词管理

管理系统使用的所有提示词模板，展示描述、键名、更新时间和操作人。

- **编辑**：在弹窗中修改提示词内容
- **重置**：将提示词恢复为系统默认值

---

### 3.5 修改密码（`/rag/admin/change-password`）

管理员可在右上角用户菜单中进入修改密码页面。输入当前密码和新密码（最少 8 位）并确认即可完成修改。

## 6. 典型使用流程

### 匿名访客快速问答

1. 打开系统，直接在输入框中提问
2. 查看 AI 流式回答，展开「来源片段」了解引用依据
3. 点击「文档控制台」浏览公开知识库

### 管理员维护知识库

1. 管理员账号登录
2. 进入「文档控制台」→「上传文档」批量导入资料，等待入库完成
3. 返回主界面提问，验证新文档是否被正确召回
4. 如需调整 AI 行为，进入「管理后台」→「提示词管理」编辑模板

### 邀请新成员

1. 管理员进入「管理后台」→「注册码管理」
2. 点击创建注册码，将生成的注册码发给新成员
3. 新成员在登录抽屉中切换到「注册」标签，输入用户名、密码和注册码完成注册

### 管理员分配权限

1. 进入「角色管理」，创建自定义角色并勾选所需权限
2. 进入「用户管理」，编辑目标用户，将其角色改为新建的角色

## 7. 注意事项

- **会话保持**：登录状态基于浏览器本地保存的双 token。若 refresh token 过期、失效或被服务端吊销，需要重新登录
- **本地存储**：对话历史保存在浏览器本地，清除浏览器数据会导致历史丢失
- **上传限制**：单文件无显式大小限制，大文件建议分批上传
- **图片问答**：采用非流式接口，需等待完整响应，不支持中途取消
- **并发上传**：批量上传采用并发策略，单个文件失败不影响其他文件
- **内置角色**：SUPER_ADMIN、ADMIN、USER 为系统内置角色，不可删除
