# Knowledge Copilot 前端功能手册

> 本文档面向最终用户，系统阐述前端界面中的所有功能模块、角色权限及典型使用流程。

---

## 1. 产品概述

Knowledge Copilot 是一款基于 **RAG（检索增强生成）** 架构的智能知识库问答系统。用户可以通过自然语言向系统提问，系统会先从已入库的文档中检索相关片段，再基于检索结果生成精准回答。系统同时支持图片上传问答、文档管理与用户权限控制。

**核心能力一览：**

| 能力 | 说明 |
|------|------|
| 智能问答 | 基于知识库文档的流式对话，带引用来源 |
| 图片问答 | 上传图片并提问，支持多模态理解 |
| 文档管理 | 上传、查看、下载、删除知识库文档 |
| 权限管控 | 匿名浏览、成员操作、管理员后台的三级权限 |
| 提示词管理 | 管理员可动态调整系统提示词模板 |

---

## 2. 角色体系

系统采用三级角色模型，不同角色可访问的功能范围逐级递增。

### 2.1 匿名访客（未登录）

- 无需账号即可使用核心问答功能
- 可浏览公开的文档列表和文档详情
- 可下载公开文档
- **不可**上传、删除文档
- **不可**访问管理后台

### 2.2 已登录成员（MEMBER）

- 拥有匿名访客的全部能力
- 可查看完整的文档列表（含内部文档）
- **不可**上传、删除文档（需要管理员权限）
- **不可**访问注册码管理和提示词管理

### 2.3 管理员（ADMIN）

- 拥有成员的全部能力
- 可上传单文件或整个文件夹到知识库
- 可删除已入库的文档
- 可生成、禁用、删除一次性注册码
- 可查看和编辑系统提示词模板
- 可重置提示词为默认值

## 3. 功能模块详解

### 3.1 智能问答（主界面）

主界面为对话式布局，底部是输入区，中间是消息流。

#### 3.1.1 提问方式

- **文本提问**：在底部输入框中输入问题，按 `Enter` 发送（`Shift + Enter` 换行）。
- **图片提问**：点击输入框左侧的「图片」图标，选择图片文件后输入问题并发送。支持 `jpg`、`jpeg`、`png` 格式。

#### 3.1.2 回答展示

- **流式输出**：AI 回答以打字机效果逐字呈现。
- **思考过程**：若模型支持推理，会显示可折叠的「思考过程」卡片，展示模型内部推理链，并记录思考耗时。
- **来源片段**：回答下方可展开「来源片段」，列出系统检索到的相关文档段落、文件名及相似度得分。
- **复制回答**：每条 AI 消息右上角提供「复制」按钮，可一键复制完整回答文本。

#### 3.1.3 对话控制

- **取消生成**：生成过程中，发送按钮变为「停止」按钮，点击可立即中断当前流。
- **清空对话**：顶部工具栏提供「清空对话」按钮，可清空当前会话上下文并释放服务端对话状态。
- **对话持久化**：对话历史自动保存在浏览器本地（`localStorage`），刷新页面后自动恢复。

#### 3.1.4 检索参数

顶部工具栏提供数字输入框，可调整 `maxResults`（默认 64），控制每次检索返回的文档片段数量。数值越大，召回率越高，但可能引入更多噪声。

---

### 3.2 文档集合（左侧抽屉）

点击顶部「文档集合」按钮，从左侧滑出文档管理抽屉。

#### 3.2.1 文档列表

- 展示所有已入库文档的文件名、文档 ID 和切分段数。
- 匿名访客仅能看到公开文档列表；登录后可见完整列表。
- 列表为空时，已登录用户会看到引导上传的提示。

#### 3.2.2 文档上传（需登录）

- **上传文档**：点击「上传文档」按钮，支持多选文件批量上传。
- **上传文件夹**：点击「上传文件夹」按钮，可递归上传整个文件夹中的合法文件。
- **支持格式**：`.pdf`、`.txt`、`.docx`、`.xlsx`、`.pptx`、`.jpg`、`.jpeg`、`.png`
- **实时进度**：上传过程中通过 SSE（Server-Sent Events）实时展示解析、切分、向量化、入库各阶段的进度条和文字说明。
- **批量上传**：支持同时上传多个文件，显示 `(当前/总数)` 进度。
- **取消上传**：上传过程中可随时点击「取消」中断。

#### 3.2.3 文档操作

- **查看**：点击「查看」按钮，进入文档详情页，展示文档的元信息（标题、分类、关键词、段落列表）。
- **下载**：点击「下载」按钮，弹出下载链接弹窗，可复制链接或直接下载原文件。
- **删除**（管理员专属）：点击「删除」按钮移除文档及其所有向量片段。

#### 3.2.4 文档详情页

从文档列表点击「查看」后进入二级抽屉，展示：

- 文档标题、文件名、分类、段落数、时间戳
- 关键词标签云
- 所有文本切分段落，按 `chunkIndex` 编号展示，支持滚动浏览

---

### 3.3 用户认证（右侧抽屉）

点击顶部「用户登录」按钮，从右侧滑出认证抽屉。

#### 3.3.1 登录

- 已注册用户输入用户名和密码即可登录。
- 登录状态保持至会话过期或主动退出。

#### 3.3.2 注册（注册码模式）

- 新用户必须持有管理员发放的**一次性注册码**才能注册。
- 注册成功后，该注册码立即失效。
- 注册界面提供「用户名」、「密码」、「注册码」三个字段。

#### 3.3.3 退出登录

- 已登录用户可在抽屉顶部点击「退出」按钮注销当前会话。
- 退出后界面自动回退到匿名访客权限。

#### 3.3.4 注册码管理（管理员专属）

管理员登录后，认证抽屉会额外展示「注册码管理」区域：

- **生成注册码**：填写备注和有效期（可选），点击「生成一次性注册码」。
- **查看列表**：展示所有注册码的状态（可用 / 已使用 / 已禁用 / 已过期）、创建者、使用时间、使用人。
- **禁用**：对状态为「可用」的注册码，可手动禁用。
- **删除**：可永久删除注册码记录。

---

### 3.4 管理后台（右侧抽屉，管理员专属）

管理员登录后，顶部工具栏会出现「管理」按钮，点击后从右侧滑出管理后台抽屉。

#### 3.4.1 提示词管理

- **查看列表**：展示系统中所有可配置的提示词模板（如系统提示词、重排提示词等），含最近更新时间。
- **编辑**：点击「编辑」按钮，在弹出的模态框中修改提示词内容，支持多行大文本编辑。
- **重置**：点击「重置」按钮并确认后，可将当前提示词恢复为系统默认值。

## 5. 界面布局与交互

### 5.1 主界面布局

```
┌─────────────────────────────────────────────────────────────┐
│  [文档集合]  [maxResults]  [清空对话]  [管理*]  [用户登录]   │  ← 顶部工具栏
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌──────────┐                                    ┌──────┐  │
│  │ AI 头像  │  Knowledge Copilot                 │ 气泡 │  │  ←  assistant
│  └──────────┘                                    └──────┘  │
│                                                             │
│                        ┌──────┐  ┌──────────┐              │
│                        │ 气泡 │  │ 用户头像 │               │  ←  user
│                        └──────┘  └──────────┘              │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  [图片]  [输入你的问题...]  [发送/停止]                     │  ← 底部输入区
└─────────────────────────────────────────────────────────────┘
```

> `*`「管理」按钮仅在管理员登录时显示。

### 5.2 抽屉与弹窗

| 面板 | 触发方式 | 位置 | 说明 |
|------|---------|------|------|
| 文档集合 | 顶部「文档集合」按钮 | 左侧滑出 | 文档列表与上传 |
| 文档详情 | 文档列表中点击「查看」 | 左侧滑出（覆盖列表） | 分段详情展示 |
| 下载链接 | 点击「下载」按钮 | 中央弹窗 | 复制或触发下载 |
| 用户认证 | 顶部「用户登录」按钮 | 右侧滑出 | 登录/注册/注册码管理 |
| 管理后台 | 顶部「管理」按钮 | 右侧滑出 | 提示词管理 |

### 5.3 响应式适配

- **大屏（≥1280px）**：消息气泡最大宽度 920px，左右留白充足。
- **中屏（720px ~ 1280px）**：消息气泡最大宽度自适应，内边距减小。
- **小屏（<720px）**：内边距进一步压缩，消息气泡占满全宽，抽屉变为全屏宽度。

## 6. 典型使用流程

### 流程一：首次使用（匿名访客）

1. 打开系统，直接进入主界面。
2. 在底部输入框提问，系统即时流式返回答案。
3. 点击消息中的「来源片段」展开，查看引用依据。
4. 点击顶部「文档集合」浏览公开文档。
5. 如需上传文档，点击「用户登录」进行注册或联系管理员获取注册码。

### 流程二：管理员维护知识库

1. 使用管理员账号登录。
2. 点击「文档集合」→「上传文档」或「上传文件夹」，批量导入资料。
3. 等待 SSE 进度条走完，确认文档入库成功。
4. 返回主界面提问，验证新文档是否被正确召回。
5. 如需调整系统行为，点击「管理」→ 编辑对应提示词模板 → 保存。

### 流程三：邀请新成员

1. 管理员登录后，打开「用户登录」抽屉。
2. 在「注册码管理」区域填写备注，点击「生成一次性注册码」。
3. 将注册码发送给新成员。
4. 新成员在注册页面输入用户名、密码和注册码完成注册。

## 7. 注意事项

- **会话保持**：登录状态基于浏览器 Cookie 会话，关闭浏览器后可能需重新登录。
- **本地存储**：对话历史保存在浏览器本地，清除浏览器数据会导致历史丢失。
- **上传限制**：单文件上传无显式大小限制，但受限于服务器配置和网络环境；大文件建议分批上传。
- **图片问答**：图片问答采用一次性非流式接口，上传后需等待完整响应，不支持中途取消。
- **并发上传**：批量上传采用并发策略，多个文件同时处理，任一文件失败不会影响其他文件。
